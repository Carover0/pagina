Infraestructura independiente para explorar, monitorear e interactuar con redes blockchain.

### Qué vas a encontrar

- **Nodos completos:** infraestructura propia para distintas redes.
- **Exploradores:** consulta de bloques, transacciones y direcciones.
- **Monitoreo:** estado de nodos, sincronización, recursos del servidor y servicios.
- **Herramientas propias:** estadísticas, endpoints de estado y utilidades desarrolladas para interactuar con las redes.

### Filosofía

- **Autogestión:** infraestructura operada y administrada por mí.
- **Desarrollo propio:** herramientas construidas para necesidades concretas, sin frameworks innecesarios.
- **Simplicidad:** HTML, CSS y JavaScript nativo.
- **Privacidad:** sin publicidad ni trackers.
- **Transparencia:** datos accesibles y verificables directamente.
- **Independencia:** control sobre la infraestructura, los servicios y las herramientas.

El proyecto se desarrolla y mantiene de forma independiente, priorizando el autoalojamiento, la autonomía técnica y el acceso directo a los datos de las redes.
